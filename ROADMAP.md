# Roadmap

## v0.1.0

- Native Android handoff form.
- Readiness scoring for missing critical care details.
- Local draft save and restore.
- Plain-text export through Android share intents.
- Unit tests and CI build.

## Next

- Add editable call-owner and emergency-vet trigger fields.
- Add multi-medication input instead of the current single-medication form.
- Add PDF or image export for caregivers who prefer printable cards.
- Add larger-text mode for quick boarding-desk review.
- Add optional backup contact and clinic address fields.

## Later

- Add multiple dog profiles.
- Add offline encrypted storage for recurring caregivers.
- Add import/export for saved templates.
- Add localized strings after the core workflow stabilizes.
