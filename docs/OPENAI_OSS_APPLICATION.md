## Short Description

DogHandoffCard is a native Android app for creating senior-dog care handoff
cards before family care, boarding, or temporary pet sitting.

## Maintainer Qualification Draft

I am the creator and primary maintainer of DogHandoffCard, an early-stage native
Android open-source app that helps owners prepare safer senior-dog care handoff
cards for temporary caregivers. I maintain the Android app code, readiness
scoring logic, tests, documentation, issue templates, CI workflow, and release
process. The project is small but actively maintained and designed for clear
public contribution.

## API Credits / Codex Usage Draft

I would use Codex to accelerate maintenance of this Android project: improving
the readiness scoring rules, expanding test coverage, reviewing pull requests,
triaging issues, preparing releases, and implementing small caregiver-focused
features such as multi-medication support, printable export, and better
accessibility. I would not use credits to fabricate adoption metrics or automate
spam.

## Honest Current Status

- It does not yet have broad adoption, package downloads, or external
